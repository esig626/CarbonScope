# E. coli native acceptance evidence

`frozen_projection_parity.csv` records the 96 frozen projection comparisons for the two accepted physical flux conditions (`biomass` and `acetate`). The current executable acceptance tests load the complete model, isotope model, direction-activity data, frozen optima and positive fixtures directly from `fluxemu.real_model` package data.

The historical migration handoff archive is not required by the native acceptance path.
